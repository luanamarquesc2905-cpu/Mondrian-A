# Mondrian A

Para este exercício, comecei por criar um canvas de 800 por 784, cujo background tinha como valores RGB (240,240,240). A seguir fui criando quadrados e retângulos com o código "Draw" e "rect". Para adicionar cor aos mesmos usei o "fill" e utilizando uma referência de RGB tentei aproximar ao máximo das cores da obra original. Para adicionar as linhas pretas que contornam as formas usei o "line" e defini o "StrokeWeight" com 15px para as linhas horizontais e as verticais com 10px.
